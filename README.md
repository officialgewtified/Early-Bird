# Early Bird

Brand-new Solana meme coins, checked for the usual scams and ranked by how early they are.

- **Fresh / Hot**: new and trending coins from DEX Screener, Jupiter and GeckoTerminal, read straight from your phone (free, no keys).
- **Scam checks**: RugCheck, Jupiter and GoPlus data turned into plain checks; each coin gets Passed, Caution or Sketchy.
- **Hold (Survivors)**: coins that already lasted 6 hours to 3 weeks and are still being traded, for buying and holding instead of flipping. A Hold tag means holders and buying are still growing without a giant pump.
- **Check**: paste any coin address or link for the full check.
- **Watch**: watchlist with rug alerts, a buy tracker and a weekly play-money limit.
- **Record**: an hourly GitHub Action (`track.js`) writes down what the Fresh list showed and re-checks each coin 1, 6 and 24 hours later, so you can see how each kind of coin really did. Survivors coins are also re-checked at 3, 7 and 30 days.
- **Practice money**: a GitHub Action (`autopilot.js`) runs four fake-money players every 5 minutes: the coach's signals, every passed coin, random coins, and a Holder that buys Survivors and holds up to 30 days.

Not financial advice. Most new coins lose value even when they pass the checks.

Setup: Settings > Pages > Deploy from a branch > `main` / root. The site lives at https://officialgewtified.github.io/Early-Bird/
